# دكانة (Dokkana)

متجر إلكتروني للسوق المصري: ملابس وإكسسوارات رجالي وحريمي + إلكترونيات.

## الملفات

- `index.html` — واجهة المتجر (الأقسام، المنتجات، السلة، إتمام الطلب)
- `admin.html` — لوحة تحكم الأدمن (الأقسام، المنتجات، الطلبات، الإعدادات)
- `firebase-config.js` — بيانات مشروع Firebase (تتعبى مرة واحدة)
- `firestore.rules` — قواعد حماية قاعدة البيانات (تتلصق في Firebase Console)

## التشغيل

1. تتعمل قاعدة Firebase (خطواتها عند عبدو)
2. تتعبى `firebase-config.js`
3. الملفات تترفع على الريبو، والموقع يشتغل على GitHub Pages
